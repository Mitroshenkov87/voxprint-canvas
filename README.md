# Voxprint AI Canvas

Local text-to-image generation app of the Voxprint AI Media Suite. Everything runs on your own GPU; no cloud service is required.

> Status: early development. No releases yet.

## Requirements

- **OS:** Windows 11 24H2 or newer, or a Linux distribution released in 2025 or later.
- **GPU:** NVIDIA GeForce RTX 40 series or newer. PCs without a supported NVIDIA GPU are not supported.
