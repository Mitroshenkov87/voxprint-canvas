# Voxprint AI Canvas

Local text-to-image and image-to-image generation for the Voxprint AI Media Suite. Everything runs on your own GPU.

The [command line](cli.md) is generated from the app. [Enhance](enhance.md) improves a prompt with the text encoder that already ships with Z-Image-Turbo. The [API reference](api/pipeline.md) is generated from the Python docstrings. Shared files and the resource manifest are described in [Shared resources](shared-resources.md).

The [roadmap](https://github.com/Mitroshenkov87/voxprint-canvas/blob/main/ROADMAP.md) lists the next version and the plans after it.
