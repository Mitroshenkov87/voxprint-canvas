New:

- Text to image and image to image run on your own GPU. A 24 GB card can also use Creative and instruction edit.
- The first run downloads the pinned model files. Later runs reuse them.
- Pictures can be saved as AVIF, JPEG XL, WebP, or JPEG.
- `voxprint-canvas --selftest --json` reports whether this PC is ready to generate.
- `voxprint-canvas generate --prompt "..." --aspect 16:9 --out picture.avif --json` writes one image. Add `--output-size 4k` to make the long side 3840.

Fixed:

- A model file is refused when its SHA-256 does not match the pin.

Install the Windows setup, or unpack the Linux archive and run `./install.sh`. The download does not include the GPU libraries or the model files. Those are fetched on the PC. HEIC still needs a system codec.
