Changed:

- Photoshoot uses a new scenario text model of about 8 GB. It is downloaded the first time a scenario or an improved prompt needs it, and it is unloaded before the pictures are made.

Fixed:

- Photoshoot scenarios are read more reliably. A scenario reply with extra text around it is accepted, and an unusable reply is asked for again once.
- When a series stops, the window shows a short stop message and `photoshoot --json` reports a stop `code`.

Install the Windows setup, or unpack the Linux archive and run `./install.sh`. The download does not include the GPU libraries or the model files. Those are fetched on the PC. HEIC still needs a system codec.
