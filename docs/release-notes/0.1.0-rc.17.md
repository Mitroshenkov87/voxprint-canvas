Changed:

- Photoshoot plans its scenarios more steadily. When the scenario text model leaves frames out, the series fills them with planned frames, so a series is less likely to stop before its pictures are made.
- `photoshoot --json` reports `scenario_source`: `writer`, `mixed` or `planned`.
- VOXPrint AI Canvas has a new icon for the app window, the taskbar, Setup and the installed app entry.
- Setup adds one Start menu entry, **VOXPrint AI Canvas**, in the **VOXPrint AI Suite** folder. The older guide and uninstall shortcuts are removed on update. Uninstall from **Settings → Apps → Installed apps**.
- The English and Russian guides open from **More → Help** in the Canvas window.
- Setup can add a desktop shortcut. The box is off by default.

Install the Windows setup, or unpack the Linux archive and run `./install.sh`. The download does not include the GPU libraries or the model files. Those are fetched on the PC. HEIC still needs a system codec.
