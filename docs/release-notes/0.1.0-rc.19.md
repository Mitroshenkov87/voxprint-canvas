Changed:

- The prompt box, the actions and the settings now sit in a left panel, and the picture fills the right side.
- Photoshoot frames now vary pose and framing. The look stays consistent through the shared description.

Fixed:

- A Photoshoot series and a multi-image batch keep one loaded pipeline, including its memory placement, for the whole run. It is released when the run ends, when the text model needs the memory, when the mode, tier, or model changes, and when a generation fails. A machine with 64 GB of RAM or more may keep that pipeline loaded between runs. Smaller machines load it from disk again on the next run.
- When a frame is blocked with the same scenario stop that already ends a series before the first frame, the series stops. Frames already saved stay, and no later frame is written.

Install the Windows setup, or unpack the Linux archive and run `./install.sh`. The download does not include the GPU libraries or the model files. Those are fetched on the PC. HEIC still needs a system codec.
