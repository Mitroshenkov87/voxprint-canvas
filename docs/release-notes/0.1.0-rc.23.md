Fixed:

- A Photoshoot series of a person keeps one appearance on every frame. Later frames follow the first frame, so the face stays the same while the pose can still change.
- Each shot asks for one photo, a single frame. Where the picture model accepts a negative, collage, grid, panels and split screen are named there.
- The scenario writer runs on the GPU and is unloaded before the pictures. The timing line records its device and the time to load and to write. When it cannot stay on the GPU, the log records why. It also stops once it has enough text for the frames that were asked for.
- On a 16 GB card the picture model is offloaded when keeping it fully on the card would spill into system memory. The timing line records the peak VRAM. The writer and the check models are unloaded before that model loads. The checks use the GPU when the card has room, and the CPU when it does not.
- A Photoshoot series keeps the image model loaded for every frame, including the FP8 weight cast on a 16 GB GPU. `series.json` records the stated age.

Install the Windows setup, or unpack the Linux archive and run `./install.sh`. The download does not include the GPU libraries or the model files. Those are fetched on the PC. HEIC still needs a system codec.
