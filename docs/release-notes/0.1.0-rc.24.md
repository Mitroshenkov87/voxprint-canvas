VOXPrint AI Canvas 0.1.0-rc.24, build 23.

Fixed:

- A Photoshoot series now prepares every frame, then cooks the series in one pass. The text encoder encodes every prompt during prep and is unloaded before the pictures. Cook keeps the transformer and the VAE, and passes the stored prompt embeddings. The first frame can anchor the later frames without loading a second copy of the weights.
- The timing line records the per-frame sampling time, the total series time, and the peak VRAM. `--vram-trace` writes a VRAM line to voxprint.log before and after each load, unload, and stage.
- Each shot is one photograph. A shot line that describes a collage, a grid, panels, a sequence, or a before/after is dropped. The picture is the model's native square frame. The appearance leads the subject line, ahead of the scene, and stays inside the text encoder's token cap.
- An empty failure from the picture model is recorded in voxprint.log with its type and traceback.

Install the Windows setup, or unpack the Linux archive and run `./install.sh`. The download does not include the GPU libraries or the model files. Those are fetched on the PC. HEIC still needs a system codec.
