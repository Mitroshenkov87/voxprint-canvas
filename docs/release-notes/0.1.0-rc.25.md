VOXPrint AI Canvas 0.1.0-rc.25, build 24.

Fixed:

- On a 16 GB card, prep loads only the text encoder and its tokenizer. It encodes every prompt, moves the embeddings to the CPU, unloads the encoder, and returns the card to about zero before cook. The encoder runs in FP8 when those embeddings stay close to BF16. A fallback to BF16 or the CPU is written to the log with a reason code.
- Cook loads the transformer and the VAE. On 16 GB those weights are FP8, and each frame moves its embedding to the GPU. The full pipeline is not placed on the GPU during prep.
- A 16 GB stage keeps one heavy model. The card is checked between stages, and a stage that would pass 14 GB does not run. A fallback out of FP8 is logged. The check models keep their current weights. They are unloaded before a heavy stage and loaded again afterwards, and a check is never skipped.
- `--vram-trace` records each CUDA module with its dtype and size, and the peak allocation.

Install the Windows setup, or unpack the Linux archive and run `./install.sh`. The download does not include the GPU libraries or the model files. Those are fetched on the PC. HEIC still needs a system codec.
