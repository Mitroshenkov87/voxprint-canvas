VOXPrint AI Canvas 0.1.0-rc.26, build 25.

Fixed:

- A Photoshoot series was spending minutes on the CPU with the GPU idle. The text encoder's comparison pass and, when the move onto the GPU ran out of memory, the scenario writer both kept running on the CPU. They now run on the GPU, one model at a time, and a series stops instead of continuing on the CPU when the GPU is available.
- The picture model is loaded and cast once per series. The VAE decodes on the GPU. The timing line records load, cast, place, sampling, VAE decode, and save separately, and a long stage writes a heartbeat so a stall shows up in the log.
- The scenario writer records its device and tokens per second.

Install the Windows setup, or unpack the Linux archive and run `./install.sh`. The download does not include the GPU libraries or the model files. Those are fetched on the PC. HEIC still needs a system codec.
