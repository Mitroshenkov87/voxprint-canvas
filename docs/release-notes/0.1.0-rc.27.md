VOXPrint AI Canvas 0.1.0-rc.27, build 26.

Fixed:

- The first frame of a Photoshoot series died in the VAE after sampling, and the series wrote no pictures. The latents are now on the same device and the same dtype as the VAE immediately before decode. On a CUDA machine the VAE decodes in BF16.
- A long stage writes a heartbeat line to voxprint.log, including when Canvas is started with pythonw and when the log file is briefly locked.
- The text encoder was opened from disk more than once in one series, and the scenario writer's weight hash was computed again on every open. Each model is loaded once. The hash and the FP8 cast are reused. The encoder and the scenario writer are read straight onto the GPU.

Install the Windows setup, or unpack the Linux archive and run `./install.sh`. The download does not include the GPU libraries or the model files. Those are fetched on the PC. HEIC still needs a system codec.
