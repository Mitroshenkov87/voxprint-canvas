# VOXPrint AI Canvas 0.1.0-rc.29

- Multi-frame series are phase-batched: all frame prompts are prepared first, the picture model loads once and renders every frame while resident, and one VAE session decodes them all. No per-frame model swaps.
- Model loads are serialized, so the scenario writer always loads in bf16 (it could come out in fp32 before).
- Frames follow the prompt's own appearance; a random built-in look no longer overrides it.
- `--places different` now gives each frame its own place and pose.
- Per-phase VRAM peaks and per-frame render and decode times are logged.
