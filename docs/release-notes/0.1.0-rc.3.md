New:

- Instruction edit on a 24 GB GPU uses the published Qwen-Image-Edit-2511 FP8 mirror. `voxprint-canvas generate --edit-instruction "..." --input in.png --out out.avif --json` edits one image. The window shows the pack size and the estimated time before the download, and the pack is recorded in the shared manifest. `--selftest` reports the mirror as published.
- The shared manifest is schema 1, so Canvas can install beside another suite app that already wrote that file.
- The suite runtime is Python 3.14 with PyTorch 2.11.0 for CUDA 13.0, torchvision 0.26.0, and the GPU ONNX Runtime 1.31.0. TensorRT 10.16.1.11 is its own component.
- The installed folder includes `tools/` and `scripts/vm_test.ps1` and `scripts/vm_test.sh`.

Fixed:

- Setup no longer stops when the shared manifest was written by another suite app.
- Package download uses PyPI as the main index. torch and torchvision are pinned to the CUDA 13.0 builds, so numpy 2.5.4 is taken from PyPI.
- Default AVIF quality is 80 with 4:4:4 chroma and speed 6. JPEG XL distance is 1.0. WebP quality is 90.
- The startup window is the approved splash: a centred 960×540 card, 12 px corners, and a progress shimmer. The 2× image is a Lanczos placeholder because the Enlarge CLI was not available to upscale it.
- 4K output hands Enlarge a lossless PNG and shows Enlarge's error code and message. An adult prompt that states an age of 30, or a lens marked in millimetres, is no longer stopped.
- A finished adult picture is kept when no face is estimated under 18. A face in the 20-29 range no longer counts as younger.
- A face that looks about 20 to 25 is kept. The picture check targets a clearly younger face, and a stated age of 20 or more can support an ambiguous face only. It cannot keep a picture whose face is clearly a child. The 20 to 25 measurement uses face crops of clothed portraits with a recorded age.
- The shared startup window and manifest will come from voxprint-common. Canvas still implements shared runtime schema 1 locally.

Install the Windows setup, or unpack the Linux archive and run `./install.sh`. The download does not include the GPU libraries or the model files. Those are fetched on the PC. HEIC still needs a system codec.
