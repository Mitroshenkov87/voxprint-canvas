# VOXPrint AI Canvas 0.1.0-rc.30

- The Russian interface is removed. The window, Setup, the Help menu and the user guide are English only; the Russian guide PDF is no longer built or attached to the release. Prompts can still be written in Russian or another language, and **Improve prompt** still rewrites them in English.
- Startup no longer re-reads every installed model file. A file whose size and time match its stored record is not hashed again, so the startup window closes much sooner on a relaunch (about 41 GB read per launch before, about 7 GB now).
- Models are no longer loaded into memory while the window sits idle after startup. They load with the first picture, so that picture takes longer than the next ones.
- Importing a LoRA no longer re-hashes the 20 GB picture model to confirm it is installed.
- **Manage models** starts VOXPrint MDL from the program folder again, so it opens when that folder is not on PATH.
- Expert mode: the drop-down fields are as wide as the number fields beside them. **Picture size** is now **Frame size**, so it is not confused with **Image size**, and **Exact size** offers **Same as Image size** instead of **Match the choice**.
- The old unused window and its startup code are removed.
