# VOXPrint AI Canvas 0.1.0-rc.31

Fixed:

- Two Canvas processes on different graphics cards now run side by side. The "GPU is busy" lock is kept per card (by the card's UUID, following `CUDA_VISIBLE_DEVICES`) instead of once per machine; two processes on the same card still wait for each other. The command line takes the lock before it loads any model, so a busy card is reported in seconds and no memory is used on it first.
- `generate --out picture.png` writes a lossless PNG. Before, PNG was refused with "PNG output is not available".
- `--out` is checked before any model loads. A missing folder is created, with its parents; a folder that cannot be created or written stops the command at once with a clear message, instead of after the picture was made.
- Photoshoot: each shot's framing, camera, pose and foreshortening wording is honoured when the idea describes a person in detail. The shot's own wording now leads its line and the person's appearance follows. A framing or pose list written in the idea ("vary pose and framing: …") gives one item per shot, in order, instead of every item being sent to every shot, which could produce a multi-view sheet in each frame. The idea's backdrop and light follow the appearance. Series wording such as "across frames" no longer leaves stray punctuation in the line.
