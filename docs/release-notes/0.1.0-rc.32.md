# VOXPrint AI Canvas 0.1.0-rc.32

Added:

- `photoshoot --negative TEXT` sets a negative prompt for every frame. The negative prompt is checked like the prompt: if it is refused, the command stops the same way as for a refused prompt and nothing is generated. Picture pipelines that take no negative prompt ignore it.
- `batch --manifest file.json [--out DIR]` runs many prompts or shot lines in one command. Each entry can have its own negative prompt, seed, picture count and folder name. The manifest is checked strictly and `--out` is prepared before any model loads; a broken manifest exits with code 2 and a message naming the entry. The scenario writer loads once and the picture model loads once for the whole batch. Every prompt and negative prompt is checked like the prompt before anything is drawn; a refused entry is recorded in `batch.json` and draws nothing, and the other entries continue. Every picture is checked before it is saved.

Changed:

- The window keeps the picture model loaded between generations, so the next picture in the same session starts without reading the model from disk again. It is let go when the window closes, when the graphics card does not have room to keep it, and before Enlarge or the text writer needs the card. Changing the model, tier or LoRA loads it again, as before.
