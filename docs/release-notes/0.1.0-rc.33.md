# VOXPrint AI Canvas 0.1.0-rc.33

Added:

- `canvas.toml`: an optional settings file read once at startup with the existing knobs only (gpu, placement, keep-warm timeout, writer on/off, steps). An unknown key or a bad value falls back to its default with one log line. Command-line flags still win.
- `--gpu N` picks the graphics card per process. The card is pinned before CUDA starts, and the per-card lock follows the physical card.
- A stall watchdog: a stage that makes no progress is stopped with a clear error and a non-zero exit, and `batch.json` is still written.

Changed:

- The per-card lock heals itself: a lock left by a process that no longer runs is taken over with a log line. A running owner still gives `gpu_busy`.
- `batch.json` lists every entry with a result: ok, partial (`frames_short`), refused, or error with a reason. An exception in one entry no longer hides it.
- With `--lora`, a batch loads the base model and the LoRA once. A full card ends the batch with a clean `vram` or `gpu_busy` error per entry and exit code 1 instead of a crash. Raw Model Forge LoRA `.safetensors` files load like `.voxlora`.
- The z-image-turbo transformer loads straight onto the card in FP8 when there is room, instead of a full BF16 copy in RAM. Cache release no longer stops the process on an error, and running out of RAM while loading becomes a `vram` error.
- The window shows the saved picture, or the real error in the status line. It no longer shows stand-in pictures.
- Expert mode starts at Turbo values (8 steps, CFG 1).
- Manage models lists the models on disk on a computer without CUDA.
