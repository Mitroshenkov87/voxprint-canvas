# VOXPrint AI Canvas 0.1.0-rc.34

Fixed:
- Two jobs on two cards at once no longer crash. A job keeps a model in RAM only when enough free RAM is left for the other job; otherwise it reads that model from disk again.
- A failed RAM copy no longer ends the job; the model stays usable without the RAM copy.
- LoRA files load again: the installer now includes peft 0.21.2.
- A LoRA that cannot be loaded now reports the real cause instead of "does not fit on GPU", and its memory is freed.
- AVIF pictures now show in the preview and thumbnails.
- Saved settings that still equal the old defaults (20 steps, CFG 7.0) move to the Turbo defaults (8 steps, CFG 1.0). Values you changed are kept.
