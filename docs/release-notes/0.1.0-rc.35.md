# 0.1.0-rc.35

## Fixes

- Two jobs at once on ram96, or a LoRA job beside another job, no longer abort. The hot cache now copies weights to pageable memory and leaves pinning to the shared park budget. A failed park or release is logged as `hot skip` and the job continues.
- A LoRA file whose weights reach no layer of the model (for example, tensors with the wrong shapes) now stops with `lora.invalid` and exit 2 instead of drawing without it.

## Unchanged

- Offloading to system memory when GPU1 is full stays as it is.
