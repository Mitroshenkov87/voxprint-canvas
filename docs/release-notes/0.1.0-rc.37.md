# 0.1.0-rc.37

## Changes

- WebP is the default file type. Pictures save as lossy WebP (quality 90), which stays a setting. Photoshoot series and the Forge hand-off save lossless WebP. PNG, JPEG and AVIF stay options; nothing forces PNG.
- The series contact sheet (`overview.*`) and `series.zip` work with any frame type, not only PNG.
- How a picture was made (prompt, seed, steps, base model, LoRA name, strength and SHA-256) is written into WebP, AVIF and JPEG as XMP, with an EXIF copy, and into PNG as UTF-8 text chunks. JPEG XL is written without it, because the encoder takes no metadata. "Save metadata" stays on by default.
- voxprint-common 0.6.1. After a CUDA fault the worker sends its reply and exits with code 75 through `reply_and_exit`. The host restarts it as planned: the job counts as finished and no crash bar is shown.

## Unchanged

- The content gate, LoRA cross-base behaviour and the UI apart from the default file type.
