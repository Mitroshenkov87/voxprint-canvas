# 0.1.0-rc.39

## Changes

- Z-Image-Turbo is the default text-to-image model again. MOSS-Image is an optional Manage models download: it is never auto-downloaded or required, and the compact row stays listed for later. This supersedes the MOSS-default note in 0.1.0-rc.38.
- voxprint-common 0.7.0 (wheel SHA-256 `e0100f6ea42e62ce0d310695ab34bfdcd9227e15c71cdac4fb9e5b1e35b1f6ee`, commit `1d5b89c`) in pyproject, constraints, CI, installers and smoke scripts. That wheel makes Z-Image-Turbo the shared default (`model.default` / `model_default()` return `z-image-turbo`), keeps full Z-Image (`z-image`) as a separate optional id, ships the Turbo quality presets (4/8/16 steps, CFG 0.0, Euler), accepts guidance 0.0, and drops the `moss-image-compressed` index row. The bundled index retires `mirror-z-image-turbo`; `z-image-turbo` is the single Turbo row (`Mitroshenkov87/voxprint-mirror-z-image-turbo` @ `a853c26e`).
- The shipped runtime stays Python 3.14.8 at `shared/runtime/py314-torch2.11-cu130`. `requires-python` stays `>=3.14`. Required CI stays on Python 3.14.
- An experimental `test-py315` job probes Python 3.15 and is allowed to fail. Setup keeps the Python 3.14 standalone builds. The planned next runtime is `cpython-3.15.2+20261026`, after `onnxruntime-gpu` and `imagecodecs` publish regular cp315 wheels.

## Unchanged

- The content gate.
