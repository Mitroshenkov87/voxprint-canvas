# 0.1.0-rc.39

## Changes

- Z-Image-Turbo is the default text-to-image model again. MOSS-Image is an optional Manage models download: it is never auto-downloaded or required, and the compact row stays listed for later. This supersedes the MOSS-default note in 0.1.0-rc.38.
- voxprint-common 0.7.0 (wheel SHA-256 `582ed667ef51896086b6f70c85148c525ea24b5c3dacb64f546a76486d311eca`, commit `241ac452`) in pyproject, constraints, CI, installers and smoke scripts. That wheel makes Z-Image-Turbo the shared default (`model.default` / `model_default()` return `z-image-turbo`), keeps full Z-Image (`z-image`) as a separate optional id, ships the Turbo quality presets (4/8/16 steps, CFG 0.0, Euler), accepts guidance 0.0, and drops the `moss-image-compressed` index row. The bundled index retires `mirror-z-image-turbo`; `z-image-turbo` is the single Turbo row (`Mitroshenkov87/voxprint-mirror-z-image-turbo` @ `a853c26e`).
- The shipped runtime stays Python 3.14.8 at `shared/runtime/py314-torch2.11-cu130`. `requires-python` stays `>=3.14`. Required CI stays on Python 3.14.
- An experimental `test-py315` job probes Python 3.15 and is allowed to fail. Setup keeps the Python 3.14 standalone builds. The planned next runtime is `cpython-3.15.2+20261026`, after `onnxruntime-gpu` and `imagecodecs` publish regular cp315 wheels.
- The `[gen]` extra now accepts `torch>=2.11,<2.15` and `torchvision>=0.26,<0.30`, so a plain `pip install .[gen]` can resolve when a compatible newer CUDA wheel is already present (for example torch 2.14.1 with torchvision 0.29.2). The installer still keeps its exact lock (`torch 2.11.0+cu130`, `torchvision 0.26.0+cu130`) in `constraints.txt`.
- `render_batch` preflight now checks that the gate's Python packages import, including OpenCV 5's `cv2.utils.logging` API, and exits 2 with a clear message before any job if they are missing or unusable. OpenCV 4.10 lacks that API; a YuNet check then failed closed with `classifier_error`.
- When a job is blocked by a `SafetyError`, the per-image JSON records the exception class and, if present, the `__cause__` type and a one-line message (no prompt text).

## Unchanged

- The content gate.
