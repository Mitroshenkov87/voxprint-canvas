New:

- A prompt can be enhanced and translated into English before a picture is made. The button uses the text encoder that already ships with the picture model.
- Instruction edit on a 24 GB GPU uses the published Qwen-Image-Edit-2511 FP8 mirror. `voxprint-canvas generate --edit-instruction "..." --input in.png --out out.avif --json` edits one image. The window shows the pack size and the estimated time before the download, and the pack is recorded in the shared manifest. `--selftest` reports the mirror as published.

Fixed:

- A finished adult picture is kept when no face is estimated under 18. A face in the 20-29 range no longer counts as younger.
- A face that looks about 20 to 25 is kept. The picture check targets a clearly younger face, and a stated age of 20 or more can support an ambiguous face only. It cannot keep a picture whose face is clearly a child. The 20 to 25 measurement uses face crops of clothed portraits with a recorded age.

Install the Windows setup, or unpack the Linux archive and run `./install.sh`. The download does not include the GPU libraries or the model files. Those are fetched on the PC. HEIC still needs a system codec.
