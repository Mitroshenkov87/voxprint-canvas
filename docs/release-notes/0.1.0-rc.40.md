# 0.1.0-rc.40

## Changes

- Linux distributions released in 2024 or later, including Ubuntu 24.04 LTS, are accepted. The previous floor was 2025, which refused 24.04.
- Set `VOXPRINT_ALLOW_UNSUPPORTED_DISTRO=1` to continue with a warning on an older or otherwise unsupported Linux distribution. The override does not apply to Windows or macOS.
- Installer constraints for torch and torchvision now use the same ranges as the `[gen]` extra (`torch>=2.11,<2.15`, `torchvision>=0.26,<0.30`). The tested CUDA 13.0 default remains `torch 2.11.0+cu130` and `torchvision 0.26.0+cu130` in `constraints-cuda.txt`, inside that range.

## Unchanged

- The content gate.
