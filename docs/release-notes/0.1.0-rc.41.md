# 0.1.0-rc.41

## Changes

- LoRA alias and trigger. A LoRA can carry a readable alias (`voxprint.subject.alias`, in the form `vox_<name>`, lowercase letters, digits and underscores, at most 32 characters) next to its rare trigger. Type the alias in the prompt, or nothing at all: Canvas swaps the alias for the trigger and puts the trigger at the start of the final prompt when it is missing, without repeating one that is already there. The prompt box keeps what you typed. This applies to the main window, the command line, `render_batch`, Photoshoot, and the edit, inpaint and Use-image flows.
- The chip beside the LoRA name shows the alias, or the trigger when the LoRA has no alias. Clicking it inserts the alias, or the trigger for an older LoRA. A LoRA without an alias key gets no alias made up from its file name; it is auto-insert only.
- Two LoRAs that ask for the same alias no longer shadow each other. The later one is renamed with `_2`, `_3` and so on, and a note says so.
- A LoRA's recommended strength (`voxprint.lora.recommended_strength`, for example `"1.0"`) is now its default strength. When it is missing or cannot be read, the default is 1.0. `render_batch` uses it when `--lora-strength` is not given.
- Photoshoot keeps the trigger. Every shot line starts with the selected LoRA's trigger after the line is cut to fit the text encoder, with room kept for it, so a long idea can no longer cut it off. Without a LoRA nothing changes.
- Photoshoot scenario writer. With 18+ on, the writer request is framed as consensual adult fiction. A refusal or a reply with no shot lines is asked once more, and any shot still missing is filled from the planned shot list (scene, pose, camera, place), so a series is not stopped only because the writer declined. The same retry and planned shots apply with 18+ off, where the existing outfit boundary still holds.
- The scenario writer is now Huihui Qwen3 4B Instruct 2507 (`huihui-ai/Huihui-Qwen3-4B-Instruct-2507-abliterated`, Apache-2.0), pinned to upstream commit `c9bd464550d4078c72af0dd22aa18d0437868ce3` with a SHA-256 for every file. It downloads from the VOXPrint mirror only (`Mitroshenkov87/voxprint-huihui-qwen3-4b-instruct-2507-abliterated`), pinned to mirror revision `6e368340799452e5cba7a1e423120c7b0bc0473d`. The writer is a required download, installed with the default pack, but it is not the default generator: Z-Image-Turbo stays the default.
- The signed model index is serial 13. It lists the writer (`qwen3-4b-writer`, required, not the default) with a signed descriptor. `tools/check_model_index.py` now checks the writer's files against that descriptor by path, size and SHA-256, and refuses an index older than serial 13.
- Photoshoot batch: the first prompt check and the writer now see the same text as the encoder, with the LoRA alias swapped for the trigger and the trigger put first. Before, that first check could see the alias.

## Unchanged

- The content gate.
