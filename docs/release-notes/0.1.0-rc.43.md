# 0.1.0-rc.43

## Changes

- In Simple mode, the Random seed box sits at the bottom of the panel. The Expert seed field and lock stay in the Expert side panel; they do not share the Simple column.
- The Simple 18+ box is in a More section at the bottom of the panel. The section starts collapsed, so the box is not shown in the main panel until More is opened. It still sets only the stored 18+ value and stays in sync with the Expert box.
