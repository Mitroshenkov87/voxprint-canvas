# 0.1.0-rc.45

This release sits on `v0.1.0-rc.44`. The published `v0.1.0-rc.44` tag and its assets are unchanged. Build 43, still "Tavnit".

## Changes

- The VAE decodes in the dtype it was loaded with. Decode only moves the VAE to the GPU, as stock diffusers does; it no longer casts every weight to bfloat16 at decode time (the rc.44 "kept in float32" warning).
- When FP8 layerwise-casting hooks are removed before decode, the stored weights are first upcast to the hook's compute dtype, so a hooked VAE never decodes on FP8 weights.
- A shared decode-noise check (`canvas/models/decode_noise.py`) runs on every decoded picture. A picture that decodes to grain is not saved; generate, batch, Photoshoot and the window stop with "The decoder produced noise, so no picture was saved." (`inference.decode_noise`, exit 1).
- `tools/gpu_decode_check.py` is a standalone GPU check for base Z-Image-Turbo (seed 1616, 8 steps, shift 3.0, bfloat16): the Canvas decode, a stock float32 VAE decode of the same latent, and a full stock pipeline run. It writes the three PNGs, `report.json` and `run.log` to `--out` and prints one verdict line. On an RTX 4090 Laptop (16 GB) it passed: all three images are clean and the Canvas decode matches the stock float32 decode at 36.9 dB.

## Unchanged

- The content gate.
- The 18+ on/off policy.
- voxprint-common stays pinned at 0.7.1.
- The published `v0.1.0-rc.44` tag.
