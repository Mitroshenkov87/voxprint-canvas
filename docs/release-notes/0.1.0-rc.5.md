Fixed:

- 4K output unloads the picture model, including the text encoder and VAE, before Enlarge runs. Canvas checks that free GPU memory is above the amount Enlarge declares, releases the shared GPU lock for that step, and starts Enlarge with a clean environment.
- `voxprint-canvas --selftest` only reads the machine. It does not download models or wheels, and the JSON report is the only text on stdout. A file that was already checked is not hashed again unless its size or time changed. `--selftest --deep` checks every file again.
- torchao is installed from PyPI with an exact pin. The CUDA wheel index is used for torch and torchvision only.
- TensorRT is skipped on Python 3.14, where no wheel is published. The self-test records that note and still passes.
- `CANVAS_VRAM_CAP_GB` and `--vram-cap-gb` limit the GPU memory Canvas will use and select the tier from that limit.

Install the Windows setup, or unpack the Linux archive and run `./install.sh`. The download does not include the GPU libraries or the model files. Those are fetched on the PC. HEIC still needs a system codec.
