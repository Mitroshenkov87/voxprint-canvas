Changed:

- Setup installs voxprint-common 0.3.1 from the sha256-checked release wheel. Git is not required.
- Torch and torchvision are installed from the CUDA 13.0 index at the exact pins. Other packages come from PyPI.
- A release-candidate title is the product name, the version tag, and the build number.

Install the Windows setup, or unpack the Linux archive and run `./install.sh`. The download does not include the GPU libraries or the model files. Those are fetched on the PC. HEIC still needs a system codec.
